#model

Модель дома

---
## Параметры модели

| Параметр | Тип                      | requred    | Описание                                                                            |
| -------- | ------------------------ | ---------- | ----------------------------------------------------------------------------------- |
| id       | `number`                 | `requried` |                                                                                     |
| edges    | `Array<StreetInterface>` | `reqiured` | Список `id` домов, с которыми он соединен улицей                                    |
| category | `number`                 | `required` | `id` категории дома                                                                 |
| time     | `number`                 | `required` | Среднее время прибывания                                                            |
| price    | `string`                 | `required` | Стоимость места<br>Принимает три возможных значения: `бюджетно`, `средне`, `высоко` |
| weather  | `boolean`                | `reqiured` | Зависит ли от плохих погодных условий                                               |
 
 ---
### Типы зданий

| Категория        | Пример                | Среднее время пребывания | Стоимость        | Погода     |
| ---------------- | --------------------- | ------------------------ | ---------------- | ---------- |
| Магазин          | супермаркет           | 20–40 мин                | бюджетно         | не зависит |
| Ресторан         | кафе / ресторан       | 40–90 мин                | средне/высоко    | не зависит |
| Парк             | городской парк        | 60–180 мин               | бесплатно        | зависит    |
| Театр            | театр                 | 120–180 мин              | средне           | не зависит |
| Музей            | художественный музей  | 90–150 мин               | средне           | не зависит |
| Кинотеатр        | киноцентр             | 120–150 мин              | средне           | не зависит |
| Спортзал         | фитнес-центр          | 60–120 мин               | средне           | не зависит |
| Церковь          | Храм Христа Спасителя | 30–120 мин               | бесплатно/средне | не зависит |
| Университет      | учебное заведение     | 60–240 мин               | бесплатно        | не зависит |
| Детская площадка | детская плозадка      | 30–60 мин                | бесплатно        | зависит    |
